# The Spark Hack Series | Presented by NVIDIA (Toronto)

Welcome to the hackathon! This workspace is set up to help your team of 7 builders win the NVIDIA Spark Hack Series.

## 📅 Schedule
- **Day 1 (May 29):** Hacking begins 9:00 PM Onwards.
- **Day 2 (May 30):** Progress check-in 6:30 PM, Overnight hacking.
- **Day 3 (May 31):** **Submissions Due 11:00 AM**, Judging 12:00 PM - 2:30 PM.

## 🎯 Challenge Tracks
All submissions must align with one of these tracks using **[City of Toronto Open Data](https://open.toronto.ca/)**:

1. **Economic Systems**: AI agents for better economic decisions, unlocking opportunities, or optimizing costs.
2. **Public Services**: Tools to simplify navigation of public systems and improve accessibility of city resources.
3. **Urban Operations**: Systems that improve real-time city functions and optimize infrastructure.

## 🛠️ Technical Requirements & Judging (100 Points)
- **Technical Execution & Completeness (30 pts)**: Functional system, no crashes, technical depth (Simulation, RAG, Fine-Tuning).
- **NVIDIA Ecosystem (30 pts)**: Must use **NIMs, RAPIDS, cuOpt, Modulus, or NeMo**. 
  - *Note: Simple GPT-4 API calls get 0 points here.*
- **Value & Impact (20 pts)**: Non-obvious insights and usability for city planners/foreman.
- **Innovation & Execution (20 pts)**: Creative combinations of models and performance optimization.

## 💰 Bounties
- **Best Use of NVIDIA Nemotron**: Focus on leveraging Nemotron models locally.

## 📂 Project Structure
- `data/`: Store Toronto Open Data files here.
- `notebooks/`: For data exploration and prototyping.
- `src/`: Core application logic and system engineering.
- `scripts/`: Utility scripts for processing or setup.
